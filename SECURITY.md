# Security Policy

## Supported versions

Security fixes are provided for the latest released version of CoverDrop.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature on the CoverDrop repository instead.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Please avoid including sensitive PDFs or personal information in reports.

CoverDrop processes PDFs locally and does not intentionally upload their contents. A vulnerability that causes unexpected file access, command execution, or network transmission should be treated as security-sensitive.
